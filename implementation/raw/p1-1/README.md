# P1-1：问题一独立求解

运行：

```powershell
python implementation/raw/p1-1/solve_p1_1.py
```

程序只读取上级目录中的两个原始数据目录，所有结果写入当前目录：

- `outputs/`：最大安全载荷、可行组批候选、第1小问基准组批、第2小问多目标结果、第3小问返航余量敏感性及运行摘要；
- `figures/`：最大安全载荷柱状图、能量利用率热力图、组批架次构成图、多目标权衡图、返航余量敏感性图。

模型口径：

1. 依据DEM确定航段最高地面高程，巡航高度取其上方50 m，服务区作业高度取地面上方30 m；
2. 水平能耗由题目给出的载荷—航程曲线反推，爬升附加能耗采用重力势能除以爬升效率，下降附加能耗按题设取0；
3. 货箱不可拆分、同一服务区内组批、质量/体积/返航能量均作为硬约束；
4. 小规模服务区使用0-1集合划分，大候选池采用保约束的快速组批回退，以保证程序可以完成全部余量情景分析；
5. 返航余量情景包括10%、15%、20%、30%、40%，若单箱也无法安全往返，则标记为不可行而不伪造架次结果。

项目根目录已有代码和结果文件不会被本程序修改。
