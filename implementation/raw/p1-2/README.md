# P1-2：局部 Pareto 前沿与全局妥协方案

运行：

```powershell
python implementation/raw/p1-2/solve_p1_2.py
```

方法流程：

1. 复用 `q1_2_common.py` 的候选架次、能耗和作业时间口径；
2. 对每个服务区求架次、能耗、时间三个单目标集合划分解；
3. 对局部解进行非支配过滤；
4. 通过Minkowski合并生成全局Pareto前沿；
5. 用等权Chebyshev距离选择最终均衡方案。

结果和图形分别写入 `outputs/` 和 `figures/`，不修改项目根目录的原有代码和结果。

默认 `MAX_EXTRA_N=0`，即使用三个单目标解生成稳定的局部Pareto候选。若希望对每个服务区继续扫描“最小架次以上”的固定架次数，可将该参数改为1、2或3；这会增加S001服务区的MILP计算时间。程序设置了30秒单个MILP时间上限；若HiGHS在时间上限前已经返回可行整数解，则保留该可行解并在后续重新检查货箱覆盖，硬约束仍然有效，但该局部目标不宣称严格最优。
