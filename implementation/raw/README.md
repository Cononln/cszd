# raw：原始实验实现

这套代码来自 `D题实现代码`，包含根目录公共脚本以及 `p1-1` 至 `p4-4pro` 等多组实验入口。

## 环境

```powershell
python -m pip install -r implementation/raw/requirements.txt
```

## 示例

```powershell
python implementation/raw/q1_1.py
python implementation/raw/q2_1.py
python implementation/raw/q3_1.py
python implementation/raw/q4_1.py
```

各 `p*` 目录中的脚本是独立候选实现。代码统一读取仓库的 `data/raw/`；目录内现有 CSV/TXT/JSON 为原始运行结果。
